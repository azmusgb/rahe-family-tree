# Unified archive search contract

One search surface should eventually rank People, alternate names, surnames, Families, Places, Stories, Sources, Claims and research items while preserving each result's canonical route and evidence state.

Requirements: keyboard navigation, deterministic ranking, useful empty state, direct deep links, no transient query persistence unless explicitly promoted to durable continuity, and mobile placement below the page hero/context rather than above it.

The existing People search remains authoritative until the unified index has parity tests; v23 must not remove a working search path before replacement coverage exists.
