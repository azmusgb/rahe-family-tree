# v23 definition of done

v23 is not a visual version bump. It is complete only when the repository has durable ownership boundaries.

Navigation: one taxonomy, detail-aware transient Back, no route-state persistence.
Tree: one measurable render lifecycle, primary canvas first, secondary intelligence deferred, calibrated budgets.
Person: one section controller per viewport with exact desktop restoration.
Home/Search: concise launch hierarchy and one coherent archive-search direction.
Research/Evidence: canonical claim states exposed without promotion.
CSS/runtime: legacy version ownership retired rather than hidden behind aliases.
Accessibility: automated and manual critical journeys certified.
Release: exact-head CI and production SHA certification.
