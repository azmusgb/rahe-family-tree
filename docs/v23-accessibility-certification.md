# v23 accessibility certification

Critical journeys: Home -> Person -> Tree -> More -> Search -> Evidence.

Automated gates must cover accessible names, landmarks/headings, focus visibility, modal containment and return, Escape behavior, keyboard-only navigation, reduced motion, forced colors, 44px phone targets, zoom/reflow and horizontal overflow.

Manual certification must verify screen-reader route announcements, Tree canvas discoverability, evidence-state wording, focus order after dynamic rendering, and breakpoint restoration.

A release cannot be certified from an accessibility scan alone; the critical journeys require browser interaction coverage and a recorded manual pass.
