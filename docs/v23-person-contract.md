# Consolidated Person experience

One controller should own Person section navigation per viewport. The durable information hierarchy is Identity -> Relationships -> Life story -> Evidence -> Research.

Mobile may suppress redundant navigation but must restore desktop markup exactly at the breakpoint. Deep links, keyboard navigation, reduced motion, accessible section names, quick actions and evidence links are required. Existing v17/v20/v21 selectors are migration implementation details and should be retired after semantic selectors have equivalent regression coverage.
