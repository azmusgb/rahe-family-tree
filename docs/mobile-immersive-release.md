# Immersive mobile family experience

This release intentionally makes the phone experience visually and spatially distinct from the desktop archive while preserving the same canonical genealogy, evidence, privacy, relationship, and source semantics.

## Mobile composition

- editorial paper-toned Home cover with an unmistakable phone-first hierarchy
- concierge-style Continue Exploring and recent-person surfaces
- dark application tab bar with a circular elevated Tree action
- vertical Families catalogue rather than a desktop-style horizontal card strip
- full identity-cover Person profiles with sticky section navigation
- true canvas Tree mode with page chrome removed
- full bottom-sheet More navigation
- premium shared treatment for media, stories, timeline, places, and research routes
- no canonical data or evidence-state mutation

The production stylesheet URL also carries an additional `surface=immersive` query key so previously cached v20 CSS cannot mask the redesigned surface on iOS/Safari.
